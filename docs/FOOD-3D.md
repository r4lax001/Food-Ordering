# จานอาหาร 3D หน้าแรก

โมเดล "จานคลุม" (cloche) สร้างด้วย Three.js และ React Three Fiber v9 ในสไตล์ clay render: โดมมุกโค้งมนพร้อมลูกบิด จานเซรามิกสีกรมท่า ส้อมและช้อนด้ามจับสีส้มแบรนด์ และเม็ดควัน/เศษอาหารลอยรอบโดม ทั้งหมดประกอบจากรูปทรงในโค้ด (lathe, capsule, sphere) ไม่ใช่ไฟล์โมเดลสำเร็จรูป

- หมุนเพลาต่อเนื่องประมาณ 14 วินาทีต่อรอบตลอดเวลาที่อยู่บนหน้าจอ ทำงานเสมอแม้ระบบตั้งค่าลดการเคลื่อนไหว เพราะเป็นพฤติกรรมหลักที่เจ้าของเว็บกำหนด ลากซ้ายขวาหรือปุ่มลูกศรเพิ่มมุมได้อิสระไม่จำกัดวง
- ดาวสี่แฉกสีขาวและสีทอง 16 ดวงกระพริบช้า ๆ รอบจานตลอดเวลา ไม่มีช่วงที่ดาวหายหมด (แต่ละดวงมีแสงพื้นฐานเสมอ วาดด้วย canvas texture ไม่ใช่ไฟล์ภาพ) ขณะ reduced motion ดาวจะนิ่ง
- หยุดเรนเดอร์เมื่อพ้นหน้าจอหรือซ่อนแท็บ รองรับ reduced motion สำหรับเอฟเฟกต์ตกแต่ง (ไอน้ำ พริกไทยกระเด็น ฝาลอยคลึง)
- ใช้ instancing สำหรับเม็ดข้าว (1,800 เม็ด มีเม็ดหอมและเม็ดกรอบสีต่างกัน) ชิ้นไก่ 120 ชิ้น และเศษพริกไทย โหลดฉากแบบ lazy จำกัด pixel ratio 1.5 และแสดงภาพอาหารสำรองหาก WebGL ใช้ไม่ได้
- เลื่อนหน้าแนวตั้งผ่านโมเดลบนมือถือได้

ไฟล์: frontend/src/components/Food3D.jsx, FoodScene.jsx, food3d.css — ติดตั้งใน hero หน้าแรกแทนภาพนิ่งเดิม (fallback ยังเป็นภาพถ่ายจานจริง)

## สิ่งที่อยู่ใต้ฝา

ข้าวสวยมีเม็ดจริงกระจายตามผิวโค้งไม่สม่ำเสมอ และผัดกะเพราไก่: น้ำซอสมันวาว ชิ้นไก่ปั้นรูปทรงไม่สม่ำเสมอหลายเฉดน้ำตาล ใบกะเพรามีเส้นกลางใบ และพริกแดงสด

## เอฟเฟกต์เปิดฝา

- สถานะเริ่มต้นคือจานคลุมปิดสนิทตามภาพอ้างอิง เมื่อชี้เมาส์ โฟกัสด้วยคีย์บอร์ด หรือเลื่อนหน้า ฝาจานจะยกลอยเอียงเบา ๆ เผยข้าวและผัดกะเพรา ส้อมและช้อนเลื่อนออกจากกันเล็กน้อย
- ไอน้ำเคลื่อนไหวจริง: ละอองสีเทาอ่อนพุ่งจากข้าวและผัด ลอยโค้งไปด้านหน้าเพื่ออ้อมขอบฝาที่ยกอยู่ ค่อย ๆ โตและจางหายวนลูป
- ตอนยกฝา เม็ดพริกไทยกระเด็นขึ้นจากผัดแล้วตกลงพักบนจาน
- ขณะฝาเปิด ฝาจะลอยขึ้นลงเบา ๆ ตลอดเวลาให้ฉากดูมีชีวิต
- เมื่อเมาส์ออกหรือเลื่อนกลับขึ้น ฝาจะปิดลงอย่างนุ่มนวล ไอน้ำหายไปพร้อมกัน
- เลื่อนหน้าถึงล่างสุดเปิดฝาเต็มที่เสมอ แม้หน้าเว็บสั้นกว่า 240px (สูตรคำนวณจากระยะ scroll ที่มีจริง)
- ผู้ใช้ reduced motion เห็นฝาเปิดทันที ไอน้ำนิ่ง ไม่มีพริกไทยกระเด็นและไม่มีการลอยคลึง

ตรวจผ่าน Chrome ด้วย `node frontend/tests/food3d.mjs` ขณะ frontend และ backend ทำงาน: เปรียบเทียบภาพ Canvas ก่อน/หลัง hover, mouse leave, scroll, มุมหมุนสองด้านจำกัดที่ ±1.570796 เรเดียน, reduced motion, จำลอง context loss แล้วแสดงภาพสำรอง และหน้าจอ 320/390/768px ไม่มีหน้าล้น ไม่มี page error ผ่านทั้งหมด

Production build ผ่าน ชุด Three.js โหลดแยกเป็น chunk ของตัวเองด้วย lazy import ไม่ได้แก้ API หรือฐานข้อมูล
